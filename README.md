# Onegin_Sorting

Программа для сортировки строк в стиле "Евгения Онегина" на чистом C (стандарт C11).

## Особенности
- Сортировка строк как в оригинальном романе
- Поддержка разных видов сортировки (прямая/обратная)
- Работа с файлами произвольного размера
- Минимальные зависимости

## Использование
```c
#include "onegin.h"

Text text = {};
TextCtor(&text, "input.txt");  // Загрузка текста

SortLines(&text, DIRECT);       // Сортировка
PrintText(&text, "output.txt"); // Сохранение

TextDtor(&text);               // Очистка
```

## Сборка
gcc -std=c11 onegin.c main.c -o onegin
